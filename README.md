# Audit Simulator

Audit Simulator is an instructional project for designing and building a custom AI assistant that supports audit-interview training. It guides learners through the work of creating a practice scenario: selecting and sanitizing a case, defining learning objectives, developing stakeholder personas and evidence, building the assistant and its scoring rubric, and testing and reviewing the result.

The repository provides a student-facing exercise guide, an instructor-oriented slide deck, and a short presentation of public audit case studies that can serve as scenario sources. The materials are standalone HTML documents and can be opened directly in a web browser; no build step is required.

## Project files

- [Audit_Simulator-Student_Guide.html](Audit_Simulator-Student_Guide.html) — Combined student guide with the exercise purpose, schedule and checklist, project phases, platform guidance, build instructions, and final submission expectations.
- [Audit_Simulator-Instructional_Slide_Deck.html](Audit_Simulator-Instructional_Slide_Deck.html) — Interactive instructional presentation for the exercise, with slide navigation, progress controls, and presenter notes.
- [Audit_Simulator-Instructional_Slide_Deck_Short.html](Audit_Simulator-Instructional_Slide_Deck_Short.html) — Concise introductory version with ten content slides, plus the title and presenter biography; includes an executive summary, public case examples, FAQs, and self-guided study notes.
- [Public_Audit_Case_Studies.html](Public_Audit_Case_Studies.html) — Navigable presentation of three public audit cases that can inform scenario selection: Tampa Bay Office Furniture, the Peace Corps Purchase Card Program, and the FBI Trilogy Project. Includes source links and notes about the limits of the public materials.
- [improv/](improv/) — Pair-based audit interview improv activity with an auditor brief, a six-month fictional Pay Buddy transaction list, three supporting scenario artifacts, and twelve auditee role cards combining four personalities with three scenario variants. Markdown artifacts include QR codes targeting their rendered GitHub Pages versions.
