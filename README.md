# Audit Simulator

Audit Simulator is a five-week instructional project in which students design and test a custom AI assistant for audit-interview practice. Students begin by rehearsing an interview in pairs, then design a focused fictional scenario, build an AI stakeholder role-play, and evaluate how well it supports questioning, evidence gathering, and audit judgment.

The repository includes a concise project introduction, a detailed instructional deck, a student guide, public audit case studies, and a pair-based improv activity with scenario artifacts. HTML presentations and GitHub Pages indexes open directly in a browser; no build step is required.
